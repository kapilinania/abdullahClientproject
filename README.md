# Abdullah Quran Academy

A premium online platform dedicated to teaching the Holy Quran, Arabic Language, and Islamic Studies.

## Live Demo
You can view the live website here: [https://kapilinania.github.io/abdullahClientproject/](https://kapilinania.github.io/abdullahClientproject/)

## Features
- **Responsive Design**: Optimized for mobile, tablet, and desktop views. Fixed horizontal overflow issues on mobile.
- **Interactive Sliders**: For testimonials and teacher profiles.
- **Course Filtering**: Easy navigation through different courses based on categories.
- **Forms Integration**: Ready for Google Sheets integration for registration, trial booking, and contact messages.
- **Modern Aesthetics**: Dark green and gold color palette inspired by Islamic art, featuring glassmorphism and animations.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS with Flexbox and Grid)
- JavaScript (Vanilla JS for slider, forms, and mobile menu)
- Font Awesome (for icons)
- Google Fonts (Lato & Amiri)

## Project Structure
- `index.html`: Home page with hero section, introduction, and featured courses.
- `about.html`: Our story, mission, vision, and teaching methodology.
- `courses.html`: Comprehensive list of courses with filtering capability.
- `teachers.html`: Profiles of certified tutors.
- `faq.html`: Frequently asked questions with accordion interaction.
- `contact.html`: Contact form and contact details.
- `free-trial.html`: Form to book a free trial class.
- `registration.html`: Enrollment form.
- `journey.html`: Student journey and roadmap.
- `privacy.html`: Privacy policy and terms.
- `assets/`: Contains CSS, JS, and image assets.

## How to Run Locally
1. Clone the repository or download the files.
2. Open `index.html` in any web browser to view the site.
